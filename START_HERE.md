## 📋 Super Simple Steps:

### 1️⃣ Create GitHub Account (2 minutes)
- Go to: https://github.com/signup
- Sign up (free)

### 2️⃣ Create Repository (1 minute)
- Click **"+"** at top-right → **"New repository"**
- Name: `expense-tracker`
- Make it **Public**
- Click **"Create repository"**

### 3️⃣ Upload Your Project (2 minutes)
**Just double-click this file:**
```
upload-to-github.bat
```
It's in this folder! It will do everything automatically.

### 4️⃣ Wait for Build (3-5 minutes)
- Go to: `https://github.com/YOUR_USERNAME/expense-tracker`
- Click **"Actions"** tab
- Wait for green checkmark ✅

### 5️⃣ Download APK (1 minute)
- Click the completed build
- Scroll to **"Artifacts"**
- Click **"expense-tracker-apk"** to download
- Extract the ZIP
- You got your APK! 🎉
